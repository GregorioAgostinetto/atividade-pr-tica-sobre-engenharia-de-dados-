# Análise Exploratória de Dados — NovaMart

## Objetivo do Projeto
Realizar uma análise exploratória da base fictícia `pedidos_novamart.csv` (20.000 pedidos concluídos e entregues) para diagnosticar a estrutura dos dados, quantificar campos sem preenchimento, identificar valores atípicos (*outliers*) e gerar recomendações práticas apoiadas em evidências estatísticas e visuais.

## Como Executar o Projeto
1. Certifique-se de ter o Python 3 e o Jupyter Notebook (ou VS Code / Google Colab) instalados.
2. Instale as bibliotecas necessárias caso ainda não possua:
   ```bash
   pip install pandas seaborn matplotlib notebook
   ```
3. Mantenha os arquivos `analise_novamart.ipynb` e `pedidos_novamart.csv` na **mesma pasta**.
4. Abra o arquivo `analise_novamart.ipynb` e execute todas as células sequencialmente (*Run All*).
